# B083-WK1-PM1-CYBERSECURITY-LAB-SETUP
KALI LINUX setup

## Project Overview

This project involved setting up a Kali Linux environment for cybersecurity learning and practical labs.

The purpose of the setup was to prepare a working cybersecurity lab where I can practice networking, web security, ethical hacking, and other cybersecurity techniques.

## Tools Used

- Kali Linux
- VirtualBox
- Burp Suite
- Firefox
- Wireshark
- Terminal

## Lab Setup Steps

### 1. Installed VirtualBox

I installed Oracle VirtualBox to create and run my Kali Linux virtual machine.

### 2. Downloaded Kali Linux

I downloaded the Kali Linux virtual machine and imported it into VirtualBox.

### 3. Configured the Virtual Machine

I configured the Kali Linux virtual machine and allocated the required resources.

### 4. Started Kali Linux

I started the virtual machine and logged into Kali Linux.

### 5. Tested the Internet Connection

I opened the terminal and tested the network connection to make sure Kali Linux could communicate with the internet.

### 6. Tested the Browser

I opened Firefox in Kali Linux and tested whether websites could load correctly.

### 7. Checked the Network Configuration

I used the terminal to check the network configuration and IP address.
